## Programmazione ad Oggetti (LT DIEF)

### Exam

* Solve **two exercises** from the [learn-java-core](https://github.com/nbicocchi/learn-java-core) repository **(45% of the final grade)**
* Answer theoretical questions on the main topics covered in the course **(45% of the final grade)**
* Present and discuss the structure and engineering choices of a **home project** **(10% of the final grade)**

### Home Project

The home project must:

* Provide value to other learners by offering insights into:

    * natural phenomena (e.g., fractal visualization), **or**
    * the Java ecosystem (e.g., benchmarking Java collections)
* Include a `README.md` clearly explaining the project goals, design, and internal structure
* Contain **250–500 lines of logic code per person**, excluding GUI and XML files
* Use **Maven** as the build tool
* Take inspiration from
  [learn-java-javafx](https://github.com/nbicocchi/learn-java-javafx/tree/main/code)

#### Frequently Asked Questions

**Can we develop the project in groups of three?**

> No. Projects may be developed individually or in pairs. Team members must have comparable coding skills. Exceptions are negatively evaluated.

**Can we use JavaScript, TypeScript, Kotlin, Dart, Swift, C++, or C#?**

> No. **Only Java** is allowed.

**Can we use external libraries?**

> Yes. One of the core motivations behind object-oriented programming is code reuse and the development of larger, modular systems.

**When is the best time to start the project?**

> The first half of the course focuses on foundational concepts that should be mastered first. It is recommended to start the project around midterm and use the second half of the course to refine the design and implementation.

**I encounter strange errors while developing. What should I do?**

> Start by copying the error message and searching for it online. Most common issues are well documented, often with dedicated answers on Stack Overflow.

## Distributed Edge Programming (LM DIEF)

### Exam

* Answer **two questions**, selected or adapted from the *Lab* sections of the course modules
* Discuss **one exercise**, selected or adapted from the *Lab* sections of the course modules

This second part of the exam may be replaced by a **home project**. In this case, the project **must**:

* Be structured as a full **course module**
* Include both a **Markdown presentation** and **executable code**
* Be clearly related to the course topics
